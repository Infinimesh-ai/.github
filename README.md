# Infinimesh.ai

Infinimesh.ai 是一个围绕**可控 AI 基础设施**和**企业级智能体运行时**的开源团队。我们帮助团队把 AI 从“体验型工具”转变为**可审计、可治理、可持续交付**的工程能力。

## 我们做什么

我们正在构建与维护一套面向实际生产场景的本地优先智能体系统：

- **本地优先部署**：支持在企业内部环境中运行与管理智能体，减少对外部依赖。
- **可审计与可追溯**：为关键决策与动作保留完整链路，支持回溯、复盘和治理。
- **工具化协作**：通过标准化 Tool/动作接口，让 AI 与外部系统更稳定地协作。
- **安全与合规优先**：通过权限、审批与隔离机制，降低高风险操作风险。

## 我们的开源项目

- [SparkClaw](https://github.com/Infinimesh-ai/SparkClaw)：一个面向高性能算力场景的本地代理运行时，强调稳态运行、可解释链路与可测试验证。
- [LocalMind](https://github.com/Infinimesh-ai/LocalMind)：面向办公与知识工作流的长期演进方向，致力于把智能体能力嵌入到实际协作场景。

我们相信，优秀的 AI 系统不只是“回答问题”，更重要的是在复杂环境中持续、安全地把事情做对。欢迎关注并参与我们的开源协作。
